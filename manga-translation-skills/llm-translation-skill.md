# 先進漫畫翻譯 LLM 應用 (LLM Translation) SKILL

本文件探討將大型語言模型 (LLM) 整合進漫畫翻譯的工作流程，建立包含上下文感知、語氣模擬、術語庫 RAG 與多模態 Vision 翻譯的架構。

## 1. 傳統機器翻譯 vs. LLM 代理翻譯

### 1.1 傳統流程痛點 (`manga-image-translator` 預設行為)
*   **單句直翻**：將 OCR 辨識出來的一個個 Bounding Box 內的字串，當作獨立的句子丟給 API。
*   **缺乏上下文**：無法分辨這句話是「同一格內的對話延續」，還是「另一個角色的回答」。導致代名詞 (你、我、他) 經常錯亂。
*   **缺乏語氣 (Persona)**：不管角色是傲嬌蘿莉還是粗獷大叔，翻出來的語氣都極度生硬、統一。

### 1.2 LLM 代理流程 (先進專案架構)
*   **頁面級別 (Page-level) 批次翻譯**：將一整頁甚至跨頁的所有 OCR 文字，依照閱讀順序 (通常是從右到左、從上到下) 排序後，一次性打包進 Prompt 交給 LLM。
*   **引入系統提示詞 (System Prompt)**：賦予 LLM 「漫畫在地化翻譯專家」的 Persona，並設定嚴格的輸出格式 (例如 JSON)。
*   **術語庫注入 (Translation Memory / RAG)**：針對不同漫畫，動態注入角色名稱、招式名稱、專有設定，確保連貫性。

## 2. LLM 翻譯 Prompt 設計技巧 (Text-only 模式)

### 2.1 系統提示詞範例 (System Prompt)
```text
你是一個精通日文與繁體中文（台灣習慣用語）的專業漫畫在地化翻譯專家。
你的任務是將提供的漫畫台詞翻譯成流暢、生動、符合角色性格的繁體中文。

【翻譯規則】：
1. 維持強烈的上下文連貫性。提供的文本是一整頁的對話，請根據前後文判斷代名詞與主角語氣。
2. 將日文狀聲詞 (如：ドーン、バキッ) 翻譯為合適的台灣狀聲詞 (如：咚！、喀啦！)。
3. 若文言文或特殊口音，請用適當的中文語氣呈現。
4. 絕對保持 JSON 格式輸出，不要包含任何多餘的解釋或 Markdown 標記。
```

### 2.2 動態術語庫注入 (RAG Injection)
在 User Prompt 的開頭，程式應該要動態查詢當前專案的字典，並拼接進去：
```text
【本專案專有術語表】：
- キャラA -> 阿爾托莉雅 (語氣：尊貴、嚴肅，稱呼自己為「我」)
- キャラB -> 閃閃 (語氣：傲慢、高高在上，稱呼自己為「本王」)
- 斬撃 (ざんげき) -> 燕返
```

### 2.3 輸入與輸出格式設計 (JSON Schema)
輸入與輸出必須帶有唯一 ID，以正確對應原圖圖塊 (Bounding Box)。

**User Prompt 輸入實例：**
```json
{
  "page_id": "001",
  "dialogues": [
    {"id": "box_1", "text": "ふん…"},
    {"id": "box_2", "text": "雑種が、"},
    {"id": "box_3", "text": "思い上がるなよ！"}
  ]
}
```

**LLM 預期輸出實例：**
```json
{
  "translations": [
    {"id": "box_1", "translated_text": "哼…"},
    {"id": "box_2", "translated_text": "雜碎，"},
    {"id": "box_3", "translated_text": "可別太得意忘形了啊！"}
  ]
}
```

## 3. 多模態 LLM 翻譯架構 (Next-Gen 架構)

### 3.1 視覺輔助翻譯流程 (Vision-Assisted Translation)
*   **告別純文字盲翻**：純文字的 OCR 無法表達畫面上的「角色表情（生氣、害羞）」、「場景（戰鬥中、日常）」、「對話框樣式（爆炸框通常代表大吼，鋸齒框可能代表內心話）」。
*   **實作方法**：
    1.  用檢測模型 (YOLO) 畫出文字框。
    2.  將「整張漫畫原圖」+「文字框座標 (或加上純數字編號標籤)」+「初步的 OCR 結果」同時丟給 GPT-4o / Gemini。
    3.  要求模型：「請參考圖片上的畫面情境，並輔助修正 OCR 可能識別錯的日文字，給出最適合當前畫面魄力的翻譯。」

### 3.2 甚至取代 OCR 與檢測階段？ (End-to-End LLM)
*   目前社群也有人在實驗，把整張原始漫畫圖直接丟給 GPT-4o，不依賴 YOLO 也不依賴 MangaOCR，直接下 Prompt：
    *   `找出這張圖片中所有的對話框，提供它們在圖片中的 (x, y, w, h) 座標，並給出裡面的日文原文與繁體中文翻譯。`
*   **建議架構**：目前大型多模態模型在輸出精確座標上可能會有偏差。較穩定的作法是**使用本地小型檢測模型 (如 ComicTextDetector) 提供邊界，再交給雲端大模型進行 Vision 翻譯。**
